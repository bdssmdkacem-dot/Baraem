# Baraem UI Audio Assets

ضع ملفات الصوت الفعلية في هذا المجلد بالأسماء الدقيقة التالية.

## `correct.mp3`
النص:
"أحسنت! إجابة رائعة!"

الاستخدام: تشغيله بعد اختيار إجابة صحيحة في القصص والألعاب وتحدي الأصدقاء.

## `try_again.mp3`
النص:
"حاول مرة أخرى! أنت تستطيع!"

الاستخدام: تشغيله بعد إجابة خاطئة بطريقة مشجعة وغير محرجة للطفل.

## ملاحظات
- لا تغيّر أسماء الملفات.
- MP3 فقط.
- صوت واضح وقصير، بدون موسيقى أو مؤثرات خلفية.
- هذه أصوات واجهة عامة، وليست مرتبطة بقصة نوح فقط.
