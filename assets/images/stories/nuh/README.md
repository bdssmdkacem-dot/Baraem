# صور قصة نوح عليه السلام

هذا المجلد مخصص للصور الفعلية لقصة نوح عليه السلام.

## الملفات المطلوبة

`nuh_1_01.png` — بداية القصة والدعوة إلى عبادة الله وحده.

`nuh_2_01.png` — نوح عليه السلام يدعو قومه بصبر، وبعض القوم يستمع وبعضهم يبتعد.

`nuh_3_01.png` — بناء السفينة بأمر الله، مع تمثيل نوح عليه السلام من الخلف أو كهيئة بعيدة دون إظهار الوجه.

`nuh_4_01.png` — دخول المؤمنين السفينة ودخول الحيوانات بأزواج في مشهد آمن للأطفال.

`nuh_5_01.png` — الطوفان والسفينة فوق أمواج كبيرة، دون رعب أو غرق أو عنف.

`nuh_6_01.png` — انتهاء الطوفان وانخفاض الماء وتوقف المطر.

`nuh_7_01.png` — استقرار السفينة وعودة الأمان والهدوء.

`nuh_8_01.png` — المشهد الختامي: أرض آمنة وخضراء، نجاة المؤمنين والحيوانات، والأمل وبداية جديدة.

## مواصفات الصور

- نفس الهوية البصرية الحالية لـ Baraem.
- 2D children's book / educational illustration.
- مناسبة للأعمار 2–13 سنة.
- نسبة 16:9.
- لا نصوص داخل الصور.
- لا شعارات أو علامات مائية.
- لا أدوات أو ملابس حديثة.
- لا إظهار وجه أو ملامح نوح عليه السلام.
- لا عنف أو مشاهد غرق أو رعب.
- جميع الصور يجب أن تبدو وكأنها من قصة واحدة متصلة، مع ثبات الأسلوب والإضاءة والشخصيات والبيئة.
